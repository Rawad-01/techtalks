# TechTalks demo script

Target length: 2–3 minutes. Use the final HTTPS URL, a real account, a prepared original article, and a community you have not joined. Keep credentials and private account information outside the recording.

| Time      | Show                                                        | Say                                                                                                                                                                 |
| --------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:15 | Homepage; briefly resize and restore desktop width          | “TechTalks is a developer community built with Next.js, Auth.js, and MongoDB. Visitors can discover stories and communities without signing in.”                    |
| 0:15–0:35 | Blogs, a search/topic filter, then an article               | “The journal includes topic filters, author details, and Markdown articles. Public blog pages use incremental static regeneration.”                                 |
| 0:35–0:55 | Communities and a community detail page                     | “Each community has its own description, members, and related articles.”                                                                                            |
| 0:55–1:15 | Click Login, show both providers, authenticate              | “Members can sign in with Google or GitHub. The app verifies the session and stores their profile in MongoDB.” Pause recording during the private provider screens. |
| 1:15–1:40 | Profile; edit a bio, save, and refresh                      | “The profile is protected. Changes persist in the database.” Keep the private email sidebar out of view.                                                            |
| 1:40–2:10 | Write a story; paste, preview, and publish                  | “Articles are validated on the server and belong to their author. Publishing makes the story available in the journal.”                                             |
| 2:10–2:35 | Join a community, refresh, find it on Profile, then leave   | “Membership changes persist. Atomic database updates prevent duplicate joins.”                                                                                      |
| 2:35–2:50 | Sign out; show Profile redirecting to Login; finish on Home | “Private pages require a valid session. Public stories remain available after logout.”                                                                              |

The article needs a title of at least 5 characters, introduction of 20, and content of 100. Record the real workflow. Resolve failures before the final take. Submit the GitHub and live URLs separately from the video.
